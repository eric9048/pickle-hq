# 🏢 합동 비서실 (pickle-hq)

박이만 사장님과 3명의 피클 비서(로빈 · 제시 · 제리), 그리고 💎 제미나이(Gemini API) · 🤖 ChatGPT(OpenAI API)가 함께 쓰는 실시간 대시보드입니다.
정적 페이지(GitHub Pages) + Firebase Realtime Database로 동작하며, 새로고침 없이 모든 기기에 즉시 반영됩니다.

## 화면 (대메뉴 → 소메뉴 → 상세)

- **💬 합동 회의실** — 사장님·로빈·제시·제리 4인과 💎 제미나이 · 🤖 ChatGPT(여섯 명)가 한 화면에서 실시간으로 대화. 하단 **누구에게 말하기** 칩(모두·로빈·제시·제리·제미나이·ChatGPT)을 골라 **[보내기]** 하나로 보내면, 고른 AI가 자동으로 답합니다(발화자는 항상 사장님). Enter 전송(Shift+Enter 줄바꿈),
  현재 안건 표시·수정, 메시지 삭제. Firebase `hq/meeting` 노드를 구독해 새로고침 없이 즉시 반영됩니다.
  말풍선마다 **↩ 답장**(인용 블록이 붙고, 인용을 누르면 원문으로 이동·강조) · **📋 복사**(클립보드, 실패 시 폴백) · **✕ 삭제**가 있고,
  상단 **☑ 선택**을 켜면 말풍선을 골라 **📋 선택 복사 · 🗑 선택 삭제**를 한 번에 할 수 있습니다. 본문은 드래그·길게 눌러 선택해 복사할 수 있습니다.
  상단 비서 3인 카드에는 **비서별 사용량 원형 그래프**(`hq/usage`)가 있고, 카드를 누르면 사용률·라벨·메모를 바로 고칠 수 있습니다.
  비서는 자기 사용량을 조회할 수 없어 **앱 '내 피클' 탭에서 확인한 값을 사장님이 직접 입력**합니다.
- **💎 제미나이 (Gemini API)** — 회의실 참여자 스트립의 `제미나이` 카드를 누르면 API 키 설정 시트가 열립니다(모델: `gemini-3.8-flash` 기본 / `gemini-3.5-flash-lite`·`gemini-3.6-flash`·`gemini-4-hydrogen` 선택, `gemini-2.5-flash`는 기존 프로젝트용).
  키가 있으면 **누구에게 말하기**에서 `제미나이`(또는 `모두`)를 골라 보내면 자동으로, 또는 본문에 **@제미나이**를 넣으면 답변을 `from: "gemini"`로 회의실에 등록합니다(안건·최근 대화 12건·진행 중 업무를 맥락으로 전달).
  호출 중에는 `💎 제미나이가 답변 작성 중...`이 표시되고, 잘못된 키·할당량 초과 등은 쉬운 말의 오류(HTTP 코드 포함)로 안내합니다.
  선택한 모델이 그 키로 쓸 수 없는 모델이면(HTTP 404) 모델 목록을 차례로 재시도해 성공한 모델로 답하고, 그 모델을 이 브라우저에 자동 저장합니다.
  ※ 2026-09-18부터 Gemini 2.5·2.0 모델은 기존 사용 프로젝트에만 열려 있어 새 키에서는 404가 나므로 기본을 3.8 Flash로 두었습니다. 키가 없을 때 `제미나이`에게만 보내면 설정 시트가 열립니다.
  **API 키는 이 브라우저의 localStorage(`pickle_hq_gemini_key`)에만 저장되며 GitHub 저장소·Firebase DB로 전송되지 않습니다.** 다른 기기에서는 다시 입력해야 합니다.
- **🤖 ChatGPT (OpenAI API) — 현재 숨김(2026-11-27)** — 사장님 지시로 참여자 카드·`누구에게 말하기` 칩·자동응답·수다방에서 빠져 있습니다(5인 체제로 복구). 코드는 남아 있어 `app.js`의 `CHATGPT_ENABLED = true`로 되돌리면 카드·칩·자동응답이 함께 복구됩니다(OpenAI 크레딧 0이면 429가 나므로 충전 후 켜세요). 아래는 켰을 때의 동작입니다.
  회의실 `ChatGPT` 카드를 누르면 설정 시트가 열립니다(모델: `gpt-4o-mini` 기본 / `gpt-4o`·`gpt-4.1-mini`·`gpt-4.1`).
  `누구에게 말하기`에서 `ChatGPT`(또는 `모두`)를 골라 보내면 자동으로 답변을 `from: "chatgpt"`로 등록합니다. 기본 모델이 404면 다른 모델로 자동 재시도합니다.
  **OpenAI 키는 이 브라우저의 localStorage(`pickle_hq_openai_key`)에만 저장됩니다.**
- **🎲 AI 수다방** — 회의실 서브탭. 로빈·제시·제리·제미나이가 서로 이름을 부르며 수다 떠는 걸 구경하는 전용 피드입니다(사장님 입력창 없음).
  **[🎲 수다 한 판 돌리기]** 를 누르면 설정된 AI가 최근 맥락을 이어받아 한마디씩 주고받습니다(ChatGPT를 켜면 제미나이 → ChatGPT 순서로 4마디, 한 키만 있으면 2마디 / `hq/lounge/messages`).
- **실시간 업무 보드** — 담당자(전체·로빈·제시·제리·사장님) 필터, 진행 중 · 대기 중 · 완료 칸반.
  카드에 상세 내용 첫 줄이 미리 보이고, 카드를 누르면 상세 시트에서 **업무 제목 + 상세 글 내용(진행 상황·다음 할 일·링크)** 을 바로 읽고 고칠 수 있습니다. 담당자 변경, 상태 이동, 삭제도 같은 시트·카드에서 합니다.
  새 업무를 추가할 때 상세 내용을 함께 적을 수 있습니다.
  상세 시트에서 **▶ 업무 실행**(저장 + `진행 중`/`executionStatus: requested` + 회의실에 실행 요청 자동 등록),
  **📢 결과 회의실 공유**(`📢 [업무 결과 보고]` 형식으로 회의실 등록 + `reported`/`completed`), **🗑 업무 삭제**(레드 버튼)를 누를 수 있습니다.
  카드에는 실행 상태 태그(▶ 실행 요청 · 📢 결과 보고)가 함께 표시됩니다.
- **상세 시트 메모** — 블로그·스레드·캠페인 상세에도 메모를 보고 저장할 수 있습니다(`note` 필드).
- **콘텐츠 현황판** — 네이버 블로그(eric_pm) 1~42호 발행/임시저장/비공개 상태, 스레드(@eric_yiman) 게시 현황, 캠페인 마감 D-day.
- **수익 · 장부 요약** — 11월 제휴 매출(쿠팡 파트너스·쇼핑커넥트)과 세차·디테일링 부업 누계.
- **메모 · 전달 피드** — 발신자(사장님·로빈·제시·제리)를 골라 남기는 실시간 메모.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (잠금 화면 + 대시보드) |
| `style.css` | 다크/라이트 테마, 반응형 레이아웃 |
| `app.js` | Firebase 연결, 실시간 렌더링, 라우팅(#해시), 상세 시트, 모든 편집 동작. 상단에 `firebaseConfig`와 접속 PIN이 있습니다 |

> 파일을 고쳐 배포할 때는 `index.html`의 `style.css?v=` · `app.js?v=` 값을 함께 올려 주세요.
> GitHub Pages가 파일을 최대 10분간 캐시하므로, 값이 같으면 새 코드가 바로 보이지 않습니다.

## 접속

- 잠금 화면에서 PIN을 입력하면 입장합니다. 인증 상태는 브라우저 localStorage에 남고, 우측 상단 **나가기**로 해제합니다.
- 대메뉴(홈·회의실·업무·콘텐츠·수익·장부)를 누르면 그 영역의 소메뉴만 보이고, 소메뉴를 누르면 상세가 열립니다.
- 주소 해시로 현재 위치를 기억합니다: `#home`, `#meeting/room`, `#meeting/feed`, `#tasks/all|doing|waiting|done`, `#content/blog|threads|campaigns`, `#revenue/all|coupang|shopconnect|detailing`. 새로고침해도 그 자리로 돌아옵니다.
- PIN을 바꾸려면 `app.js`의 `const PIN = "1247";` 값을 고쳐 커밋하면 됩니다.
- `robots` 메타로 검색 노출을 막아 두었습니다(`noindex, nofollow`).

## 참고

- 이 저장소는 공개 저장소입니다. **개인적·민감한 정보는 코드나 데이터에 넣지 않습니다.**
- 저장소에는 DB 접속 정보를 적지 않습니다. 연동이 필요한 팀원에게는 별도로 전달합니다.
